# 🤖 DaveBot's Arcade 🎮

A retro-futuristic web arcade featuring pixel art tools, Discord webhook utilities, and interactive web experiences.

## ✨ Features

- 📡 **Pixel Webhook Sender** - Send stylish Discord webhook messages with custom embeds
- 🎨 **Retro Pixel Art Design** - 90s arcade aesthetic with modern animations
- 🌟 **Interactive UI** - Smooth animations, glitch effects, and neon aesthetics
- 🚀 **GitHub Pages Deployment** - Automated CI/CD with secure secret management

## 🎯 Live Demo

Visit: [https://davebot2025.github.io](https://davebot2025.github.io)

## 🛠️ Tech Stack

- Pure HTML/CSS/JavaScript
- GitHub Pages for hosting
- GitHub Actions for automated deployment
- Discord Webhooks API integration
